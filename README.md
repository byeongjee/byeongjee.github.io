# byeongjee.github.io

Personal homepage, built with Jekyll and the Minimal Mistakes theme.

## Setup

Requires Ruby 3.3.5 (see `.ruby-version`), e.g. via rbenv:

```
rbenv install 3.3.5
bundle config set --local path vendor/bundle
bundle install
```

## Run locally

```
bundle exec jekyll serve
```

Then open http://localhost:4000.
